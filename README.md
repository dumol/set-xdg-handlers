# set-xdg-handlers
Bash script to programmatically set the handlers for file types
using the desktop files of installed apps. This is used to automatically
configure the order of file associations.

If you are tired of manually configuring what application should open by default
some file types, you can use this script to set your preferences quickly
and in a reproducible way.

See the examples in the Bash scripts for ways to configure this.

Beware that invoking this scripts resets previously existing association,
for example those set through a file manager such as GNOME's Nautilus.
